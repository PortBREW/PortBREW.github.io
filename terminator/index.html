Android on Wii U.

Terminator is an experimental Android APK recompilation project targeting the Nintendo Wii U. The goal is to bring original Android applications to Wii U hardware through code translation and a compatibility runtime.

Project status

Terminator is an experimental project. Compatibility, supported APKs and release availability are still being developed. The target is real Wii U hardware; emulator testing is not required.
